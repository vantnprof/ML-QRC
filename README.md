# ML-QRC

Multilinear Transformation for Quantum Reservoir Computing.

The current manuscript snapshot is `ML_QRC__QCE_QML2026_.pdf` (generated
2026-05-19). The notebooks needed for the manuscript experiments are listed in
[`notebooks/README.md`](notebooks/README.md).

## Reproducing The Paper Experiments

Open and run the notebooks in `notebooks/` in the order documented in
`notebooks/README.md`. The repository no longer uses Python builder scripts to
generate notebooks; notebooks are edited and maintained directly.

Generated outputs are written under `notebooks/artifacts/` when the notebooks
run. That directory, root-level `artifacts/`, and local scratch data are ignored
because they are reproducible outputs rather than source files.
